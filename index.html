Frequently asked questions

Quick answers before we start working together.

What technologies do you work with?

Mainly C#, .NET 8, ASP.NET Core / MVC and Web API on the backend, React or jQuery on the frontend, and SQL Server for databases. I also deploy apps to cloud hosting.

How long does a typical project take?

It depends on scope. A small internal tool might take one to two weeks, while a full web application with multiple modules can take four to eight weeks. I give a realistic timeline after understanding the requirements.

Do you work with existing codebases?

Yes. I regularly take over projects built by other developers, fix bugs and add features without rewriting everything unless it's really needed.

Can you handle both frontend and backend?

Yes. I can build the database, backend and user interface, or focus on just one part if that's what you need.

Do you offer support after delivery?

Yes. There's a support window after launch to fix any issues, and ongoing maintenance is available afterwards.
